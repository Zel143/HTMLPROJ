# INK FIST STUDIOS website

A multi-page website for INK FIST STUDIOS, a mock animation studio, built as a five-person group
project for a web development course.

**Live site:** https://zel143.github.io/HTMLPROJ/

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| About us | `about.html` |
| Mission and vision | `mission-vision.html` |
| Team | `team.html` |
| Portfolio | `portfolio.html` |
| Gallery | `gallery.html` |
| Animations | `animations.html` |
| Contact | `contact.html` |

## Built with

HTML, CSS and JavaScript, with Bootstrap 5.3 for the layout, navbar and off-canvas mobile menu.
Shared styles are in `styles/unified.css` and shared behavior is in `scripts/script.js`.

## Running it locally

There is no build step. Open `index.html` in a browser, or serve the folder:

```sh
python -m http.server 8000
```
